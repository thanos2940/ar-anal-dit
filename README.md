# Αριθμητική Ανάλυση (ΕΚΠΑ DIT) — Webnotes

Διαδραστικές σημειώσεις, 5-Day Study Sprint, τυπολόγιο, μοντέλα λυμένων θεμάτων εξεταστικής και flashcards για το μάθημα της **Αριθμητικής Ανάλυσης** (Τμήμα Πληροφορικής & Τηλεπικοινωνιών, ΕΚΠΑ).

## 🚀 Περιεχόμενα

- **[index.html](index.html)**: Κεντρικός κόμβος με το 5-Day Study Sprint Roadmap, διαδραστικό checklist προόδου (`localStorage`) και καθημερινά micro-drills.
- **[prerequisites.html](prerequisites.html)**: Μαθηματικά από το Μηδέν (Άλγεβρα πινάκων, παραγώγιση, Taylor, ανισότητες απολύτων, σφάλματα).
- **Θεματικές Ενότητες (Topics 1–7)**:
  - `topic1_direct_linear.html`: Άμεσες μέθοδοι επίλυσης γραμμικών συστημάτων (Gauss, LU, Cholesky, pivoting).
  - `topic2_iterative_linear.html`: Επαναληπτικές μέθοδοι γραμμικών συστημάτων (Jacobi, Gauss-Seidel, σύγκλιση).
  - `topic3_nonlinear.html`: Μη γραμμικές εξισώσεις (Διχοτόμηση, Newton-Raphson, Τέμνουσα, Σταθερό σημείο).
  - `topic4_interpolation.html`: Παρεμβολή (Lagrange, Newton, Splines, σφάλμα).
  - `topic5_integration.html`: Αριθμητική ολοκλήρωση (Τραπέζιο, Simpson, Gauss).
  - `topic6_odes.html`: Συνήθεις διαφορικές εξισώσεις (Euler, Heun, Runge-Kutta).
  - `topic7_matlab_guide.html`: Οδηγός MATLAB / Octave & έτοιμα scripts εργαστηρίου.
- **[exam_prep.html](exam_prep.html)**: Πλήρως αναπτυγμένα μοντέλα θεμάτων εξετάσεων (Types A–H) με αναλυτικά ενδιάμεσα βήματα, student traps και κανόνες αναγνώρισης.
- **[interactive_quiz.html](interactive_quiz.html)** & **[flashcards.html](flashcards.html)**: Εργαλεία αυτοαξιολόγησης και επανάληψης.

## 🛠️ Τεχνολογίες

- Pure HTML5, CSS3, ES6+ JavaScript.
- MathJax v3 για απόδοση μαθηματικών συμβόλων TeX/LaTeX.
- Zero external build dependencies (τρέχει άμεσα τοπικά ή μέσω HTTP server/GitHub Pages).
