## ⭐ ΣΥΜΒΑΣΗ ΚΟΣΤΟΥΣ ΤΟΥ ΜΑΘΗΜΑΤΟΣ (κρίσιμο για Θέμα 1.3)

Επιβεβαιωμένο από τη χειρόγραφη λύση 1.3. Αυτοί οι αριθμοί είναι *ο κανόνας* του μαθήματος:

| Πράξη | Κόστος |
|---|---|
| Επίλυση συστήματος με απαλοιφή **Jordan** | n³/2 |
| Υπολογισμός **αντιστρόφου** με Jordan | 3n³/2 |
| **Πολλαπλασιασμός** δύο n×n πινάκων | n³ |
| Πίνακας × διάνυσμα (A⁻¹b, όταν ο A⁻¹ είναι ήδη γνωστός) | n² → **αμελητέο** |

### Λυμένο πρότυπο — (A⁻¹C + BD⁻¹)x = A⁻¹b με Jordan

**α) Ωμή (brute-force) επίλυση**
- A⁻¹C : 3n³/2 (αντίστροφος) + n³ (πολλ/σμός)
- BD⁻¹ : 3n³/2 (αντίστροφος) + n³ (πολλ/σμός)
- Άθροισμα: 3n³/2 + n³ + 3n³/2 + n³ = **10n³/2 = 5n³**
- A⁻¹b : n², **αμελητέο** (ο A⁻¹ έχει ήδη υπολογιστεί)
- Επίλυση του τελικού συστήματος: n³/2
- **Σύνολο: 11n³/2 = O(11n³/2)**

**β) Μετασχηματισμός** — πολλαπλασιάζουμε από ΑΡΙΣΤΕΡΑ με A ώστε να εξαφανιστεί ο A⁻¹:

  (A⁻¹C + BD⁻¹)x = A⁻¹b  ⟹  **(C + ABD⁻¹)x = b**

- ABD⁻¹ : n³ (A·B) + 3n³/2 (D⁻¹) + n³ ((AB)·D⁻¹) = **7n³/2**
- Επίλυση: n³/2
- **Σύνολο: 8n³/2 = 4n³ = O(4n³)**

**γ) Συμπέρασμα:** μειώσαμε από O(11n³/2) σε O(4n³) — η *αλγεβρική* αναδιατύπωση πριν τους αριθμητικούς υπολογισμούς γλιτώνει ουσιαστικό κόστος, χωρίς καμία αλλαγή στο αποτέλεσμα.

> **Το κόλπο που ζητείται ΠΑΝΤΑ:** πολλαπλασίασε και τα δύο μέλη με ό,τι ακυρώνει τους αντίστροφους (εδώ τον A). Κάθε αντίστροφος που εξαφανίζεται γλιτώνει 3n³/2.

## ΤΥΠΟΣ «Newton-Raphson: συγκλίνει για κάθε x₀;» (Θεώρημα Γενικής Σύγκλισης)

Λυμένο πρότυπο: f(x) = x³ + 6x − 1 στο [0,1]. Ελέγχουμε **και τις 5** συνθήκες — αυτή ακριβώς είναι η ζητούμενη δομή απάντησης:

1. **f ∈ C²[a,b]** — «ως πολυωνυμική» (αρκεί ως δικαιολόγηση).
2. **f(a)·f(b) < 0** — f(0) = −1, f(1) = 6 ⟹ f(0)f(1) = −6 < 0 ✅ (υπάρχει ρίζα)
3. **f′(x) ≠ 0 σε όλο το [a,b]** — f′(x) = 3x² + 6 > 0 ∀x ∈ [0,1] ✅ (μονότονη ⟹ μοναδική ρίζα)
4. **η f″ διατηρεί πρόσημο στο [a,b]** — f″(x) = 6x ≥ 0 ∀x ∈ [0,1] ✅ (δεν αλλάζει κυρτότητα)
5. **|f(c)/f′(c)| ≤ b − a** στο άκρο c — παίρνουμε c = 0 (το μικρότερο άκρο):
   |f(0)/f′(0)| = |−1/6| = 1/6 ≤ 1 − 0 = 1 ✅

**Συμπέρασμα:** η N-R συγκλίνει για **κάθε** αρχική τιμή x₀ ∈ [0,1].

**β) Ο τύπος:** x_{n+1} = x_n − f(x_n)/f′(x_n) = x_n − (x_n³ + 6x_n − 1)/(3x_n² + 6)

## ΤΥΠΟΣ «1ο βήμα Jordan με μερική οδήγηση + ποιος ο επόμενος οδηγός;»

Λυμένο πρότυπο (επαυξημένος πίνακας):

```
[ 1   2  -1 | -6 ]
[ 5  -1   1 | 10 ]
[ 3   0   2 |  9 ]
```

**Βήμα 1 — οδηγός στην 1η στήλη:** max{|1|, |5|, |3|} = 5 ⟹ **R1 ⟷ R2**

```
[ 5  -1   1 | 10 ]
[ 1   2  -1 | -6 ]
[ 3   0   2 |  9 ]
```

**Απαλοιφή:** R2 − (1/5)R1 , R3 − (3/5)R1

```
[ 5   -1     1   | 10 ]
[ 0  11/5  -6/5  | -8 ]

```

**Οδηγός για το 2ο βήμα:** max{|11/5|, |3/5|} = 11/5 ⟹ **παραμένει ως έχει** (καμία εναλλαγή), οδηγό στοιχείο το **11/5**.

> ⚠️ Η μερική οδήγηση ψάχνει ΜΟΝΟ στη στήλη k, στις γραμμές i ≥ k. Όχι σε όλο τον πίνακα.

## ΤΥΠΟΣ «Παρεμβολή σε ΙΣΑΠΕΧΟΝΤΑ σημεία → Newton ΕΜΠΡΟΣ ΔΙΑΦΟΡΕΣ»

⭐ **Κλειδί που χάνουν οι περισσότεροι:** αν τα xᵢ **ισαπέχουν**, η «πλέον αποτελεσματική» μέθοδος δεν είναι οι διηρημένες διαφορές αλλά η **Newton με εμπρός διαφορές** (λιγότερες πράξεις — μόνο αφαιρέσεις, καμία διαίρεση).

Λυμένο πρότυπο: f(x) = x³+1, x = −2,−1,0,1,2 → f = −7,0,1,2,9. Ζητά f(1.5).

h = x₁ − x₀ = −1 + 2 = 1,  θ = (x − x₀)/h = x + 2

P₄(x) = f₀ + C(θ,1)Δf₀ + C(θ,2)Δ²f₀ + C(θ,3)Δ³f₀ + C(θ,4)Δ⁴f₀
      = f₀ + θΔf₀/1! + θ(θ−1)Δ²f₀/2! + θ(θ−1)(θ−2)Δ³f₀/3! + θ(θ−1)(θ−2)(θ−3)Δ⁴f₀/4!

**Πίνακας εμπρός διαφορών** (χρησιμοποιείς την ΠΑΝΩ διαγώνιο):

```
 x     f    Δf   Δ²f  Δ³f  Δ⁴f
-2    -7     7    -6    6    0      ← όλη η πάνω διαγώνιος
-1     0     1     0    6
 0     1     1     6
 1     2     7
 2     9
```

f₀ = −7, Δf₀ = 7, Δ²f₀ = −6, Δ³f₀ = 6, Δ⁴f₀ = 0

P₄(x) = −7 + 7(x+2) − 6(x+2)(x+1)/2 + 6(x+2)(x+1)x/6 + 0 = … = **x³ + 1**

P₄(1.5) = 1.5³ + 1 = 3.375 + 1 = **4.375**

**β) Σφάλμα = 0.** Δικαιολόγηση με βάση τη θεωρία: η Newton κατασκευάζει πολυώνυμο που διέρχεται από τα σημεία· ο μέγιστος βαθμός του P₄ (=4) **ξεπερνάει** τον βαθμό της f (=3), άρα η προσέγγιση είναι **ακριβής** (το πολυώνυμο παρεμβολής ταυτίζεται με την f). Ισοδύναμα: ο όρος σφάλματος περιέχει f⁽⁵⁾(ξ) = 0 για πολυώνυμο 3ου βαθμού.

**γ) Σύνθετος Simpson (n=4, a=−2, b=2):** h = (b−a)/n = 4/4 = 1

∫ f dx ≈ (h/3)(f₀ + 4f₁ + 2f₂ + 4f₃ + f₄) = (1/3)(−7 + 0 + 2 + 8 + 9) = (1/3)(12) = **4**

> Μοτίβο συντελεστών: 1, 4, 2, 4, 2, …, 4, 1 (άκρα ×1, περιττοί δείκτες ×4, άρτιοι ×2).

## ΤΥΠΟΣ «Προσδιορισμός συντελεστών wᵢ + βαθμός ακρίβειας»

Λυμένο πρότυπο: ∫₋₂² f dx ≃ w₀f(−1) + w₁f(0) + w₂f(1). a = −2, b = 2, x₀ = −1, x₁ = 0, x₂ = 1.

**Μέθοδος:** απαιτούμε ο τύπος να είναι ακριβής για f = 1, x, x², … (τόσες εξισώσεις όσοι οι άγνωστοι). Το δεξί μέλος είναι ∫ₐᵇ xᵏ dx = (b^{k+1} − a^{k+1})/(k+1):

| f(x) | Εξίσωση |
|---|---|
| 1  | w₀ + w₁ + w₂ = b − a |
| x  | w₀x₀ + w₁x₁ + w₂x₂ = (b² − a²)/2 |
| x² | w₀x₀² + w₁x₁² + w₂x₂² = (b³ − a³)/3 |

Αντικατάσταση:

```
w₀ + w₁ + w₂ = 4        (1)
−w₀ + w₂ = 0        ⟹  w₀ = w₂      (2)
w₀ + w₂ = 16/3      ⟹  2w₀ = 16/3   (3)
```

(3) ⟹ w₀ = 8/3 ; (2) ⟹ w₂ = 8/3 ; (1) ⟹ 8/3 + 8/3 + w₁ = 4 ⟹ w₁ = 12/3 − 16/3 = **−4/3**

**Άρα:** ∫₋₂² f dx ≃ (8/3)f(−1) − (4/3)f(0) + (8/3)f(1)

**β) Μέγιστος βαθμός ακρίβειας:** ολοκλήρωση τύπου Gauss δίνει ακριβή αποτελέσματα για πολυώνυμα έως βαθμού **2n − 1**, όπου n ο αριθμός των σημείων. Εδώ n = 3 ⟹ 2·3 − 1 = **5**.

> ⚠️ Το 2n−1 ισχύει όταν είναι ελεύθερα ΚΑΙ τα xᵢ ΚΑΙ τα wᵢ (Gauss). Αν τα xᵢ είναι δοσμένα/σταθερά, μόνο τα n βάρη είναι ελεύθερα ⟹ βαθμός n−1 (και n αν υπάρχει συμμετρία). Κοίτα τι αφήνει ελεύθερο η εκφώνηση.

## ΤΥΠΟΣ «ΣΔΕ με Taylor 3 όρων»

Λυμένο πρότυπο: y′ = y − x² + 1, 1 ≤ x ≤ 2, y(1) = 2, n = 1 → ζητά y(2.0).

> Στη λύση: h = (xₙ − x₁)/n. Με n = 1 ⟹ h = 1, x₁ = 1, x₂ = 2.

**Τύπος Taylor 3 όρων:**  y_{i+1} = y_i + h·y′_i + (h²/2)·y″_i

- y′ = y − x² + 1                              ⟹ y′₁ = 2 − 1 + 1 = **2**
- y″ = (y′)′ = y′ − 2x = y − x² + 1 − 2x       ⟹ y″₁ = 2 − 1 + 1 − 2 = **0**
- y₂ = 2 + 1·2 + (1/2)·0 = **4**

> **Το κλειδί:** το y″ βρίσκεται με **παραγώγιση της ίδιας της ΣΔΕ** (αλυσιδωτά), όχι αριθμητικά. Euler = μόνο οι δύο πρώτοι όροι (y_{i+1} = y_i + h·y′_i).

## ⭐ MATLAB — ΕΠΑΝΑΛΗΠΤΙΚΟΙ ΠΙΝΑΚΕΣ (το «σίγουρο» 12–20άρι του Θέματος 3)

Από το χειρόγραφο βοήθημα `Simeiwseis/Επαναληπτικοί πίνακες.pdf` + τη λύση του Θέματος 3.

**Προετοιμασία (ίδια πάντα — μάθε την απ' έξω):**

```matlab
I  = eye(n);
D  = diag(diag(A));      % διαγώνιος πίνακας με τα διαγώνια στοιχεία του A
CL = -tril(A,-1);        % αυστηρά κάτω τριγωνικό, με ΑΝΤΙΘΕΤΟ πρόσημο
CU = -triu(A, 1);        % αυστηρά άνω τριγωνικό, με ΑΝΤΙΘΕΤΟ πρόσημο
L  = inv(D)*CL;
U  = inv(D)*CU;
```

**Επαναληπτικοί πίνακες:**

```matlab
B   = L + U;                             % Jacobi
L1  = inv(I - L)*U;                      % Gauss-Seidel
Lt  = (1-t)*I + t*inv(I - L)*U;          % EGS
Lw  = I - w*inv(I - w*L)*inv(D)*A;       % SOR
Ltw = I - t*inv(I - w*L)*inv(D)*A;       % ESOR
```

**Φασματική ακτίνα (αν Z ο επαναληπτικός πίνακας):**

```matlab
x = eig(Z);
r = max(abs(x));
```

**Προς τα πίσω (backward) ESOR** — δοσμένος τύπος Lτ,ω = (I − ωU)⁻¹[(1−τ)I + τL + (τ−ω)U] μεταφράζεται κατά λέξη:

```matlab
Ltw = inv(I - w*U)*((1-t)*I + t*L + (t-w)*U);
```

> **Στρατηγική εξέτασης:** η εκφώνηση ΣΟΥ ΔΙΝΕΙ τον τύπο του επαναληπτικού πίνακα. Δεν χρειάζεται να τον θυμάσαι — χρειάζεται να ξέρεις (α) το μπλοκ προετοιμασίας (D, L, U με τα **αντίθετα** πρόσημα) και (β) ότι το `inv(X)*Y` μεταφράζει το X⁻¹Y. Μετά μεταφράζεις τον δοσμένο τύπο σύμβολο-προς-σύμβολο.

## ΤΥΠΟΣ «Σταθερό σημείο με παράμετρο λ» (1.1 — εμφανίζεται σχεδόν πάντα)

Λυμένο πρότυπο: x_{n+1} = x_n + λ(½x_n² − 1), ρίζα ξ = −√2.

**α) Διάστημα σύγκλισης.** Γράφουμε g(x) = x + λ(½x² − 1) ⟹ **g′(x) = 1 + λx**.

Συνθήκη σύγκλισης: **|g′(ξ)| < 1**

|1 + λ(−√2)| < 1 ⟹ −1 < 1 − λ√2 < 1 ⟹ −2 < −λ√2 < 0 ⟹ 0 < λ√2 < 2 ⟹ **0 < λ < √2**

Και μετά η τυπική διατύπωση: «σύμφωνα με το θεώρημα τοπικής σύγκλισης, ∃ ε > 0 ώστε η μέθοδος
να συγκλίνει στο ξ για κάθε x₀ με |x₀ − ξ| < ε, δηλαδή σε μια *γειτονιά* γύρω από το ξ».

**β) Τουλάχιστον τετραγωνική σύγκλιση.** Απαιτούμε **g′(ξ) = 0**:

1 + λ(−√2) = 0 ⟹ λ√2 = 1 ⟹ **λ = 1/√2 = √2/2**

Έλεγχος ότι είναι *ακριβώς* τετραγωνική (όχι ανώτερη): g″(x) = λ ⟹ g″(ξ) = λ ≠ 0. ✅
(Επίσης αναφέρουμε ότι όλες οι παράγωγοι της g μέχρι τάξης 2 είναι συνεχείς.)

> **Ο κανόνας-κλειδί:** τάξη σύγκλισης p ⟺ g′(ξ) = g″(ξ) = … = g^(p−1)(ξ) = 0 και g^(p)(ξ) ≠ 0.
> Γραμμική = g′(ξ) ≠ 0 · Τετραγωνική = g′(ξ) = 0, g″(ξ) ≠ 0.

## ΤΥΠΟΣ «Προσθέτω σημείο στην παρεμβολή» (το 2.1 α(i) → α(ii))

Το λυμένο πρότυπο δείχνει ακριβώς γιατί η Newton είναι «η πλέον αποτελεσματική»:
**το P₃ χτίζεται ΠΑΝΩ στο P₂ — δεν ξαναρχίζεις.**

Δεδομένα: x = −1, 0, 1, 2 · f = 3, 2, 1, −6 (f(x) = −x³ + 2). Ζητά f(1.5).

**(i) Στα 3 πρώτα σημεία** (h = 1, θ = (x − x₀)/h = x + 1):

```
 x    f    Δf   Δ²f
-1    3    -1     0        ← πάνω διαγώνιος: f₀=3, Δf₀=−1, Δ²f₀=0
 0    2    -1
 1    1
```

P₂(x) = f₀ + θΔf₀ + θ(θ−1)Δ²f₀/2 = 3 − (x+1) + 0 = **2 − x**  ⟹ P₂(1.5) = **0.5**

**(ii) Σε όλα τα σημεία — απλώς προσθέτω τον επόμενο όρο:**

```
 x    f    Δf   Δ²f  Δ³f
-1    3    -1     0    -6      ← ο μόνος νέος αριθμός που χρειάζομαι: Δ³f₀ = −6
 0    2    -1    -6
 1    1    -7
 2   -6
```

P₃(x) = **P₂(x)** + θ(θ−1)(θ−2)Δ³f₀/3! = (2 − x) + (x+1)x(x−1)(−6)/6 = 2 − x − x(x²−1) = **−x³ + 2**

P₃(1.5) = −(3/2)³ + 2 = −27/8 + 16/8 = −11/8 = **−1.375**

**β) Σφάλμα = 0**, γιατί η f είναι 3ου βαθμού, το P₃ είναι το πολύ 3ου βαθμού και διέρχεται από
όλα τα σημεία της f ⟹ η Newton «κατασκευάζει» ακριβώς την f.

**δ) Simpson για 3 διαστήματα → κανόνας 3/8** (a = −1, b = 2, n = 3, h = (b−a)/n = 1):

I ≈ (3h/8)(f₀ + 3f₁ + 3f₂ + f₃) = (3/8)(3 + 6 + 3 − 6) = (3·6)/8 = 18/8 = **9/4**

> ⚠️ **Διάλεξε σωστά τον κανόνα από το πλήθος ΔΙΑΣΤΗΜΑΤΩΝ n (όχι σημείων):**
> n = 2 (3 σημεία) → **Simpson 1/3**: (h/3)(f₀ + 4f₁ + f₂)
> n = 3 (4 σημεία) → **Simpson 3/8**: (3h/8)(f₀ + 3f₁ + 3f₂ + f₃)
> n άρτιο > 2 → **σύνθετος 1/3**: (h/3)(f₀ + 4f₁ + 2f₂ + 4f₃ + … + f_n)

## ΤΥΠΟΣ «Σφάλμα του Simpson» (η δικαιολόγηση που ζητάει το «Σχολιάστε με βάση τη θεωρία»)

Λυμένο πρότυπο: f(x) = 4x³ − 1 στο [0,2], 3 σημεία (x₀=0, x₁=1, x₂=2), h = (b−a)/2 = 1.

I ≈ (h/3)(f(x₀) + 4f(x₁) + f(x₂)) = (1/3)(−1 + 4·3 + 31) = 42/3 = **14**

Ακριβής: ∫₀²(4x³−1)dx = [x⁴ − x]₀² = 16 − 2 = **14** ⟹ σφάλμα ε = |14 − 14| = **0**

**Ο τύπος σφάλματος του Simpson (όπως τον γράφει το μάθημα):**

  E = − (h⁴(b − a) / 180) · f⁽⁴⁾(ξ),  ξ ∈ [a, b]

Εδώ: f′ = 12x², f″ = 24x, f‴ = 24, **f⁽⁴⁾ = 0** ⟹ E = −(1·2/180)·0 = **0**

> **Η φράση-κλειδί για τα «σχολιάστε»:** ο Simpson είναι ακριβής για πολυώνυμα **έως και 3ου βαθμού**,
> επειδή ο όρος σφάλματος περιέχει την **4η παράγωγο**, που μηδενίζεται. Γι' αυτό, παρόλο που
> κατασκευάζεται από παραβολή (2ου βαθμού), «τζάμπα» πετυχαίνει και τα κυβικά.

## ΘΕΩΡΙΑ ΜΙΑΣ ΓΡΑΜΜΗΣ (έτοιμες απαντήσεις σε «γιατί;»)

| Ερώτηση | Απάντηση-μοντέλο |
|---|---|
| Άμεσες vs επαναληπτικές μέθοδοι | Οι **άμεσες** έχουν σταθερό, προβλέψιμο υπολογιστικό κόστος. Στις **επαναληπτικές** το κόστος διαφέρει: ανάλογα με τον πίνακα και τη μέθοδο, ενδέχεται να διαφέρει ο αριθμός των βημάτων που απαιτούνται για να συγκλίνει η μέθοδος σε λύση. |
| Γιατί μερική οδήγηση; | Αυξάνει την **ακρίβεια** και την **ευστάθεια**, αποφεύγοντας τις διαιρέσεις με μικρούς αριθμούς — ειδικά σε πυκνά γραμμικά συστήματα. |
| Πότε ΔΕΝ χρειάζεται οδήγηση; | Όταν ο πίνακας είναι πραγματικά **συμμετρικός και θετικά ορισμένος**. |
| Τι κάνει η Μέθοδος των Δυνάμεων; | Υπολογίζει τη **μεγαλύτερη κατά μέτρο ιδιοτιμή**. Η ταχύτητα σύγκλισης εξαρτάται από τους **λόγους** της μεγαλύτερης προς τις υπόλοιπες ιδιοτιμές, καθώς και από την **αρχική επιλογή** του ιδιοδιανύσματος. |
| Ποια μέθοδο παρεμβολής αν ΔΕΝ ισαπέχουν τα σημεία; | **Lagrange** ή **Newton με διηρημένες διαφορές**. |
| Κι αν τα σημεία έχουν θόρυβο / είναι πολλά; | **Μέθοδος ελαχίστων τετραγώνων** (προσέγγιση, όχι παρεμβολή). |
| Newton-Cotes vs Gauss | Η **Newton-Cotes** επιλέγει σημεία που **ισαπέχουν** στο διάστημα ολοκλήρωσης ⟹ ακριβής για πολυώνυμα έως **n−1** βαθμού. Η **Gauss** επιλέγει και τις θέσεις ⟹ ακριβής έως **2n−1** βαθμού. (n = αριθμός σημείων) |

## ΤΥΠΟΣ «Αντίστροφος πίνακας διηρημένων διαφορών» (δίνονται κάποιες τιμές, βρες τις άλλες)

Λυμένο πρότυπο: x₀=1, x₁=2, x₂=4· f[x₀]=α, f[x₁]=2, f[x₂]=β, f[x₀,x₁]=γ=5, f[x₁,x₂]=τ, f[x₀,x₁,x₂]=1.
(Ο συγκεκριμένος αριθμός δεν έχει σημασία — η **τεχνική** έχει: γράφεις τον ορισμό και λύνεις ανάποδα.)

- f[x₀,x₁] = (f[x₁] − f[x₀])/(x₁ − x₀) ⟹ 5 = (2 − α)/(2 − 1) ⟹ 2 − α = 5 ⟹ **α = −3**
- f[x₀,x₁,x₂] = (f[x₁,x₂] − f[x₀,x₁])/(x₂ − x₀) ⟹ 1 = (τ − 5)/(4 − 1) ⟹ τ − 5 = 3 ⟹ **τ = 8**
- f[x₁,x₂] = (f[x₂] − f[x₁])/(x₂ − x₁) ⟹ 8 = (β − 2)/(4 − 2) ⟹ β − 2 = 16 ⟹ **β = 18**

> **Στρατηγική:** ξεκίνα από την εξίσωση που έχει **έναν μόνο άγνωστο**, και προχώρα αλυσιδωτά.

### Λογική αριθμοδεικτοδότηση (indexing) — κλασική παγίδα

```matlab
find(A > 1)          % ΓΡΑΜΜΙΚΕΣ θέσεις όλων των στοιχείων > 1
find(A > 1, 5)       % οι 5 ΠΡΩΤΕΣ τέτοιες θέσεις
find(A > 1, 2, 'last')  % οι 2 ΤΕΛΕΥΤΑΙΕΣ
find(A == 0, 1)      % η θέση του 1ου μηδενικού στοιχείου
A(find(A > 1, 5))    % οι ΤΙΜΕΣ στις θέσεις αυτές
```

> ⚠️ **Η MATLAB μετράει ΚΑΤΑ ΣΤΗΛΕΣ (column-major).** Για
> A = [10 3 −7 ; 0 −6 0 ; 1 0 4] η γραμμική σειρά είναι 10, 0, 1, 3, −6, 0, −7, 0, 4.
> Άρα: `find(A>1,5)` → `[1 4 9]` · `find(A==0)` → `[2 6 8]` · `A(find(A>1,5))` → `[10 3 4]`.

### Συμβολικές μεταβλητές (όταν ζητά «με χρήση συμβολικών»)

### Γραφική παράσταση πολυωνύμου από ρίζες

```matlab
p = poly([-4 5]);            % πολυώνυμο με ρίζες -4 και 5

x = -10 : h : (-10 + 2000*h);   % xi = -10 + i*h, i = 0..2000

```

```matlab
f = @(x) exp(x);

plot(x, yp);
```

### Ο επαναληπτικός πίνακας από *επαναληπτικό σχήμα* (όχι έτοιμο τύπο)

Αν σου δώσουν το σχήμα u^(k+1) = u^(k) + τR⁻¹(b − Au^(k)) με R = D − ωC_L, το μαζεύεις:

  u^(k+1) = **(I − τR⁻¹A)** u^(k) + τR⁻¹b  ⟹ επαναληπτικός πίνακας **I − τR⁻¹A**

```matlab
R   = D - w*CL;
Ltw = I - t*inv(R)*A;
```

> Αυτό είναι **ισοδύναμο** με τον τύπο του βοηθήματος `Ltw = I - t*inv(I-w*L)*inv(D)*A`,
> γιατί (D − ωC_L)⁻¹ = (I − ωL)⁻¹D⁻¹. Καλό είναι να το ξέρεις — μπορεί να σου ζητηθεί
> είτε ο τύπος είτε το σχήμα.
